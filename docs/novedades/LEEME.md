# Novedades de cada versión

Un fichero por versión, `<versión>.md` (por ejemplo `1.0.2.md`), con lo que el jugador lee cuando su PermaLocke le
ofrece la actualización. Corto: la app enseña los primeros 600 caracteres. La GitHub Action
`.github/workflows/publicar-actualizacion.yml` lo pone como notas de la release al publicarla.
